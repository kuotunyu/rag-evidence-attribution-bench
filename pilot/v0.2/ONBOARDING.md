# Annotator Onboarding

You are evaluating only whether the supplied passages answer the visible question. Do not
guess how a task was created and do not search the web or repository.

1. Confirm the UI shows your opaque `ann-*` pseudonym and the instruction hash printed in
   `PILOT_PROTOCOL.md`-bound package metadata.
2. Complete practice with coordinator-provided synthetic examples only.
3. For each task, choose `answerable`, `unanswerable`, or `unclear`.
4. For an answerable task, enter the shortest supported answer and select one or more
   independently minimal sufficient sentence sets. Mark whether the sets are exhaustive.
5. Record ambiguity, dataset defect, confidence 1–5, and a concise visible-evidence reason.
6. Autosaved drafts are editable. A submitted record is immutable; corrections use an
   amendment so the original remains available.
7. Work independently. Do not compare decisions with the other annotator.
8. Do not enter your name, email, employer, filesystem path, or other personal information.

Stop and contact the coordinator if the instruction hash differs, hidden transformation or
expected-label data appears, the browser requires network access, or a submitted record can
be overwritten.
