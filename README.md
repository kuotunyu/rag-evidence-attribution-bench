# rag-evidence-attribution-bench

Which context passages does a RAG answer *actually* depend on?

A benchmark on **HotpotQA (distractor)** comparing evidence-attribution methods for
**Qwen/Qwen3-4B-Instruct-2507** answers — attribution quality vs. supporting-fact ground truth,
faithfulness (sufficiency / comprehensiveness), latency, and peak VRAM.

> 繁體中文說明請見 [README_zh-TW.md](README_zh-TW.md).

## Quickstart

```bash
# local (CPU) environment
uv sync --extra ml --extra app

# prepare data + CPU stages
python -m rag_evidence.cli data prepare --config configs/smoke.yaml
python -m rag_evidence.cli retrieve --method bm25  --config configs/smoke.yaml
python -m rag_evidence.cli retrieve --method dense --config configs/smoke.yaml

# GPU stages run on Google Colab: notebooks/00_colab_smoke.ipynb

# aggregate + report (CPU)
python -m rag_evidence.cli evaluate --config configs/smoke.yaml
python -m rag_evidence.cli report   --config configs/smoke.yaml

# precomputed-results explorer (no model download)
docker compose up
```
