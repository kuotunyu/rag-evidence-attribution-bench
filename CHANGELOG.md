# Changelog

All notable public changes to this project are documented here.

## [0.2.0] - 2026-08-24

### Added

- Stable annotation infrastructure for blinded A/B assignment packages, append-only
  amendments, coordinator collection, third-human adjudication tooling, deterministic IAA
  gates, and privacy/publication checks.
- Source-bound handoff construction with isolated kits, reproducible wheel replay, and
  Windows and Linux platform verification.
- A deterministic synthetic engineering rehearsal covering the full tooling path.

### Research and publication boundary

- Human pilot: NOT_CONDUCTED.
- No human IAA is reported.
- Confirmatory protocol: DRAFT / NOT_AUTHORIZED.
- Synthetic rehearsal is not human evidence.
- No sandbox or prompt-injection certification is claimed.
- No model-superiority, human-annotation-quality, or confirmatory-effect claim is made.
- Stable handoff evidence is private, exact-source verification evidence and is not a Git or
  GitHub Release artifact.
